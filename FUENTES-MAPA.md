# Contornos geográficos

México y Colombia: Natural Earth, Admin 0 Countries, escala 1:110 millones, datos de dominio público.

Fuente: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Se proyectaron ambos países con la misma transformación. Las estrellas representan la conexión entre los países y no indican ciudades ni ubicaciones personales. El SVG está incluido en index.html y no necesita descargar mapas ni consultar servicios externos.
